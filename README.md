AI-Stock-Hunter
AI Stock Analysis and Automation System
About the Project
AI Stock Hunter is a personal stock analysis and automation project designed to monitor stock markets, analyze technical indicators, evaluate market conditions, and generate trading alerts.
The initial focus is NVIDIA (NVDA), with the possibility of expanding to other stocks in the future.
The project aims to use automation and AI to make stock analysis more accessible, organized, and systematic.
Key Features (Planned)
* Stock market data collection
* Technical indicator analysis (RSI, MACD, Volume)
* Support and Resistance detection
* Breakout and Breakdown analysis
* AI-assisted market analysis
* LINE notification system
* Price and technical indicator alerts
* Historical backtesting
* Paper trading and risk evaluation
Technology Stack
Technology	Purpose
n8n	Workflow automation
GitHub	Source and documentation management
JavaScript	Data processing and calculations
Market Data API	Stock market information
AI API	Analysis and explanations
LINE Messaging API	Notifications
Python may be introduced as an optional extension in future development.
Project Development
The project is being developed in six phases.
1. Foundations: n8n and GitHub
2. Market Data and Technical Indicators
3. AI Analyst and Risk Evaluation
4. LINE Bot Integration
5. Alerts, Backtesting, and Paper Trading
6. Deployment, Security, and Stability
See the detailed development plan in documentation/roadmap.md.
See the technical design in documentation/system-architecture.md.
Current Status
Phase 1 — Foundations
Initial development is being performed using an iPad Gen 9 and a web browser.
The project is currently in its documentation and infrastructure preparation stage.
Project Principles
* Prefer free and open-source tools.
* Prioritize reliable market data.
* Separate technical calculations from AI-generated explanations.
* Never assume an AI prediction is guaranteed.
* Test through backtesting and paper trading before considering real-money use.
* Never expose API keys or secret credentials in the repository.
