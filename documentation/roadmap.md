1. Project Overview

AI Stock Hunter is an automated stock analysis system built with n8n and AI.

The system aims to collect stock market data, analyze technical indicators, identify potential trading opportunities, manage portfolio information, and send notifications through LINE.

The project will prioritize free tools and services throughout the development process.

2. System Architecture

* n8n: Main workflow automation platform.
* GitHub: Project documentation and workflow backup.
* Market Data API: Stock market data collection.
* JavaScript: Data processing and technical calculations.
* AI Analyst: Stock analysis and explanations.
* LINE Messaging API: Notifications and user interaction.

Python will be considered an optional tool for future development.

4. Development Principles

1. Prioritize free tools and services.
2. Use n8n as the primary development platform.
3. Minimize manual coding.
4. Develop using an iPad initially.
5. Avoid unnecessary hardware purchases.
6. Protect API keys and credentials.
7. Verify data accuracy before analysis.
8. Test strategies with backtesting and paper trading before investing real money.
9. Never assume AI predictions guarantee profits.

5. Initial Target

The first target is to build a working n8n workflow that can retrieve NVDA stock data, process the information, and produce a basic analysis report.
